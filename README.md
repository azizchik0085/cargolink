# CARGOLINK — International Freight & Vehicle Marketplace

Ishlab chiqilgan va to'liq integratsiya qilingan xalqaro yuk va transport bozori platformasi.

---

## 📌 Asosiy Biznes Qoidalari
1. **Haydovchilar (Truck Drivers & Owner-Operators):**
   - 100% BEPUL foydalanish. Hech qanday obuna yoki to'lov yo'q.
   - Yuklarni erkin qidirish, avtomobil qo'shish, to'g'ridan-to'g'ri narx taklif qilish va chat.
2. **Logistika Kompaniyalari (Shippers & Logistics):**
   - Oylik obuna tariflari:
     - **START:** 199,000 UZS/oy (5 tagacha yuk)
     - **STANDARD:** 399,000 UZS/oy (20 tagacha yuk, 3 nafar logist)
     - **BUSINESS:** 699,000 UZS/oy (100 tagacha yuk, 10 nafar logist, analitika)
     - **ENTERPRISE:** 1,499,000 UZS/oy (Cheksiz yuklar, VIP yordam, API)
3. **Nol Komissiya (0% Commission):**
   - Platforma freight tranzaksiyalaridan hech qachon komissiya olmaydi. Barcha to'lovlar yuk beruvchi va haydovchi o'rtasida to'g'ridan-to'g'ri hal qilinadi.

---

## 🏗️ Texnologiyalar
- **Backend:** Python FastAPI, SQLAlchemy 2, Pydantic, Bcrypt, JWT, WebSockets
- **Web App:** React 18, Vite, Tailwind CSS, Lucide Icons
- **Mobile App:** React Native / Expo, Expo Router, TypeScript
- **Tests:** Pytest, HTTPX
